# TomorrowTax 🔥

**Procrastination has a price.**

An accountability app powered by loss aversion. Set a goal, stake virtual money, and if you say "I'll start tomorrow" — you pay.

Inspired by a cool startup idea shared on Twitter by [@GohilHardy](https://x.com/GohilHardy) via [@gethalfbaked](https://x.com/gethalfbaked).

## Features

- ✅ Create commitments with title, notes, deadline & stake amount
- 📊 Live dashboard: active stakes, success rate, total paid
- 🎯 Mark complete or admit failure (pay the penalty)
- 💾 Fully client-side — data persists in localStorage
- 🎨 Beautiful dark UI with gradients and smooth interactions
- 📱 Fully responsive

## How it works

1. Create a commitment and put money on the line (virtual)
2. When the deadline hits (or you feel the pull of "tomorrow") you either:
   - **I Did It!** → success, keep the stake
   - **Pay Penalty** → you "lose" the stake (tracked in Total Paid)
3. Watch your success rate climb as the cost of procrastination becomes real
